# GB Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Painel de administração de academia (vitrine com dados fictícios) no visual do Diário de Tatame: Dashboard, Alunos + ficha, Agenda & turmas, Check-ins, Graduações e Financeiro.

**Architecture:** SPA em HTML/CSS/ES modules sem build, roteamento por hash, telas no formato `{ titulo, montar(el, params, ctx) }`. Um "store" em `js/store.js` carrega os dados fictícios (gerados de forma determinística) ou o que estiver no `localStorage`, e salva cada alteração. Lógica pura em `js/logica/` com testes `node --test`.

**Tech Stack:** HTML, CSS, JavaScript (ES modules), Node 20+ só para testes (`node --test`), Python `http.server` para servir local.

**Spec:** `docs/superpowers/specs/2026-11-20-gb-admin-design.md`

## Global Constraints

- Pasta `C:\xampp\htdocs\gb-admin`, git local próprio, sem remoto; não tocar em `C:\xampp\htdocs\diario-tatame`.
- Sem Firebase, sem login, sem dependências npm, sem CDN de script. Fontes Sora/Manrope via Google Fonts (mesmo `<link>` do Diário).
- Tokens de cor copiados do Diário: `--bg:#faf9f8; --fg:#151517; --muted:#7b757d; --line:#ebe7e6; --soft:#efecea; --red:#c8201b; --red-soft:#fbeceb; --blue:#2449c9; --purple:#6b2fa8; --good:#1f8a5b; --mid:#d98a16; --white:#fff`.
- Todo texto vindo de dados passa por `esc()` antes de ir para `innerHTML`.
- `localStorage` sempre dentro de try/catch; sem ele o painel funciona só em memória.
- Data de referência "hoje" = `hojeISO()` real; os dados fictícios são gerados relativos a ela.
- Rodapé de todas as telas: "Vitrine de teste · dados fictícios".
- Servir em `http://127.0.0.1:8767` (entrada `gb-admin` no `C:\xampp\htdocs\.claude\launch.json`).
- Commits com a linha `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- `localStorage` com JSON corrompido ou de versão antiga → descarta e regenera os dados de exemplo (teste em Task 3).
- Busca de alunos com acentos/maiúsculas ("joão" acha "João") → normalizar com NFD (teste em Task 3, `normalizar`).
- Aluno faixa preta ou com 4 graus e tempo insuficiente → não aparece como apto a faixa (teste em Task 4).
- Mês sem mensalidades / aluno trancado → resumo financeiro zera sem NaN e trancado não conta como previsto (teste em Task 4).
- Rota inexistente ou `#aluno/ID` que não existe → mostra "Não encontrado" com link para Alunos, sem tela em branco (verificação no navegador em Task 6).

### Task 3: Dados fictícios e store

**Files:**
- Create: `js/dados-ficticios.js`, `js/store.js`, `tests/dados.test.mjs`, `tests/store.test.mjs`

**Interfaces:**
- Produces (`dados-ficticios.js`): `gerarDados(hojeISO: string, semente = 7) -> Dados`, determinístico (PRNG mulberry32). `Dados = { versao: 1, professores, turmas, alunos, checkins, mensalidades, graduacoes }` com:
  - `professores`: 5 `{ id, nome, faixa, graus }` (faixas preta/marrom).
  - `turmas`: as 15 da grade real (Seg/Qua 12:30, 19:00, 20:00; Ter/Qui 07:00, 19:00, 20:00; Sex 12:30, 19:00; Sáb 10:00) `{ id: "1-1230", diaSemana, horario, programa: "GB1"|"GB2"|"GB1+GB2", professorId, duracaoMin: 60 }`.
  - `alunos`: 40 `{ id: "a01".., nome, sexo: "M"|"F", nascimento, peso, telefone, faixa, graus, desde, desdeFaixa, ultimaGraduacao, status: "ativo"|"trancado", plano: "Mensal"|"Trimestral"|"Anual", valor }` — mistura: 16 brancas, 12 azuis, 7 roxas, 3 marrons, 2 pretas; 3 trancados; planos com valores 280/750/2700.
  - `checkins`: últimos 60 dias `{ id, alunoId, turmaId, data, hora }`, só alunos ativos, só em dias que a turma existe.
  - `mensalidades`: mês atual e 2 anteriores por aluno ativo de plano Mensal (trimestral/anual só no mês de vencimento) `{ id, alunoId, competencia: "YYYY-MM", vencimento, valor, pagoEm: ISO|null }`; meses passados quase todos pagos, 4 alunos com atraso.
  - `graduacoes`: histórico `{ alunoId, data, faixa, graus }` coerente com `ultimaGraduacao`.
- Produces (`store.js`): `criarStore(hojeISO, armazenamento = globalThis.localStorage) -> Store`, onde `Store = { dados, salvar(), restaurar(), novoId(prefixo) }`. Chave `"gb-admin:v1"`. Leitura inválida (JSON quebrado, `versao !== 1`, armazenamento ausente ou que lança) → `gerarDados`. `restaurar()` regenera e salva.
- Produces: `normalizar(s) -> string` (minúsculas, sem acento) em `js/ui/util-admin.js`.
